Install the file with **arm64-v8a** in its name on the Surface Duo (or Galaxy Tab S6).

## What's new

### Start screen & host page
- Full-screen pre-stream screens: no status or navigation bar (swipe from the edge to peek).
- New dark app icon with the accent-coloured "play on a display" glyph (smaller, centred play triangle).
- Start screen without loading bar; logo and "Artemide Duo" exactly centred.
- Subtitle now reads "an Artemide fork for Surface Duo and Galaxy Tab S6".
- While a session is running, the host page shows **Resume** and **Quit** instead of "Play again".
- Background waves run 10 % faster.

### App list
- **Resume** and **Quit** side by side for the running app; bottom row is now **Back · Settings · Profiles · Options**.
- **Favourites**: star button next to Play (or long-press a row); favourites get their own section.
- Real box art everywhere, Desktop included, in Moonlight's cover proportions; nicer placeholders while art is missing.
- Better Games / Apps split: tools such as PC Reboot, Restart, Shutdown, Steam Big Picture, Playnite, browsers etc. are listed under **APPS**.

### Per-game settings
- **Options → Game settings & type…** lets you set resolution, frame rate, bitrate, codec, frame pacing, HDR, virtual display and audio for one game.
- These are saved as an automatic profile ("Game · <name>") that is switched on only for that game's stream and switched back afterwards.
- You can also mark any entry as **Game** or **App**; this overrides the automatic detection.

### Surface Duo panel
- Desktop / Remote Desktop: the keyboard & trackpad panel opens on the other screen automatically when the stream starts (follows the "Keyboard button in the stream" setting).
